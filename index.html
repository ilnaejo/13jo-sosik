휴대폰 바탕화면에 저장하기 · 앱에서 더 쉽게 보는 법
  • 갤럭시: 크롬으로 열기 → 오른쪽 위 ⋮ → '홈 화면에 추가' (또는 '설치'). 카톡에서 열었다면 ⋮ → '다른 브라우저로 열기'부터.
  • 아이폰: 사파리로 열기 → 아래 공유 버튼(□↑) → '홈 화면에 추가'.
  • 인스타 즐겨찾기: 조원 프로필 → '팔로잉' 버튼 → '즐겨찾기에 추가'. 홈 왼쪽 위 Instagram 글자 → '즐겨찾기'를 누르면 조원 게시물만 모아 보여요.
  • 인스타 알림: 프로필 오른쪽 위 종 모양 → 게시물·릴스 알림 켜기. 새 글이 올라오면 바로 알려줘요.
  • 스토리: 프로필 사진 테두리가 색깔이면 24시간 안에 올린 스토리가 있어요. 사진을 누르면 볼 수 있어요.
  • 네이버 블로그: 이웃 추가 → 블로그 앱 '이웃새글'에서 새 글을 한눈에, 알림도 켤 수 있어요.

체크는 이 기기에만 저장되고 날짜가 바뀌면 새로 시작해요. 블로그 주소를 모르는 분은 '블로그 추가'로 넣어 두세요.
