휴대폰 바탕화면에 저장하기 · 더 쉽게 보는 법
  • 갤럭시: 크롬으로 열기 → 오른쪽 위 ⋮ → '홈 화면에 추가'. 카톡에서 열었다면 ⋮ → '다른 브라우저로 열기'부터.
  • 아이폰: 사파리로 열기 → 아래 공유 버튼(□↑) → '홈 화면에 추가'.
  • 인스타 즐겨찾기: 프로필 → '팔로잉' → '즐겨찾기에 추가'. 홈 왼쪽 위 Instagram → '즐겨찾기'에서 조원 글만 모아 봐요.
  • 스토리: 프로필 사진 테두리가 알록달록하면 24시간 안에 올린 스토리가 있어요.
  • 네이버 블로그: 이웃 추가 → 블로그 앱 '이웃새글'에서 새 글을 한눈에.

체크는 내 휴대폰에만 저장되고, 날짜가 바뀌면 새로 시작해요.
